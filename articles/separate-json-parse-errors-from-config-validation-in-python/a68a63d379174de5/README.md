# Separate JSON Parse Errors from Config Validation in Python

Supporting source for https://networknuts.net/knowledge-base/separate-json-parse-errors-from-config-validation-in-python/.

Tested runtime: Ubuntu 26.04 x86_64; 6 vCPU; about 12 GB RAM. Python standard library in an isolated temporary directory

Requirements: Python 3; a new empty working directory

Copy these files into a new disposable folder and run `python3 run.py`. The runner prints checks and writes details.txt. Remove only that disposable folder after inspecting the results.
