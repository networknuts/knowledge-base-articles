# Why git diff and git diff --staged Show Different Changes

Supporting source for https://networknuts.net/knowledge-base/why-git-diff-and-git-diff-staged-show-different-changes/.

Tested runtime: Ubuntu 26.04 x86_64; 6 vCPU; about 12 GB RAM. Git and Python in a new disposable local repository; no remote and no credentials

Requirements: Git and Python 3; a new empty working directory, outside an existing Git repository

Copy these files into a new disposable folder and run `python3 run.py`. The runner prints checks and writes details.txt. Remove only that disposable folder after inspecting the results.
